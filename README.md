# History The Finance

Aplicação web para controle financeiro de reformas residenciais.

## Objetivo

Registrar compras e serviços da reforma, acompanhar pagamentos e parcelas, e visualizar compromissos futuros e desembolsos mensais.

## Stack planejada

- Next.js e TypeScript
- Supabase (PostgreSQL e autenticação)
- Tailwind CSS
- Recharts
- Vercel

## Segurança

A aplicação não armazenará números de cartão, CVV, validade ou credenciais bancárias. Serão registrados apenas apelidos de cartões e contas.
